# 🏦 Object-Oriented Bank Management System (C++)

> An advanced, modular console-based Bank Management System developed in C++ applying strict **Object-Oriented Programming (OOP)** principles, design patterns, and file-based data persistence.

---

## 🚀 Key Features & OOP Architecture
- **Object-Oriented Design:** Built using robust classes and objects representing `clsBankClient`, `clsUser`, `clsScreen`, and core input/output validation libraries.
- **Encapsulation & Abstraction:** Data hiding and secure access methods to protect client records and sensitive banking data.
- **Transactions & Management:** 
  - Complete Client List management (Add, Update, Delete, Find).
  - Deposit, Withdraw, and Total Balances tracking.
  - User management and permission control systems.
- **File Persistence:** Automatic synchronization of database states using structured text files (`.txt`).

---

## 🛠️ Tech Stack & Concepts
- **Language:** C++
- **Paradigms & Concepts:** Object-Oriented Programming (Classes, Objects, Inheritance/Composition, Encapsulation, Methods).
- **File Handling:** C++ Streams (`fstream`, `ifstream`, `ofstream`) for reading and writing structured records.
- **IDE:** Microsoft Visual Studio
